# OfferPath MVP 收尾清单

> 前后端仓库各保存一份完全相同的清单。完成或调整任务时，两份文件必须在同一次开发中同步更新。

## MVP 范围

### 必须完成

- 登录、Token 刷新、退出登录与路由鉴权
- 岗位、公司、面试的真实数据管理
- 岗位状态推进与面试安排
- 岗位 URL 网页解析（非 AI，解析失败时允许手动填写）
- 仪表盘基础统计
- 默认日语、完整中文切换
- PostgreSQL 持久化、基础测试、部署与项目文档

### MVP 后再做

- 第三方登录
- AI 网页解析
- 自定义面试流程
- 复杂技能熟练度与匹配权重
- 高级动画和进一步视觉打磨

## 同步规则

1. 任务状态以本文件为准，不在聊天记录中单独维护另一套进度。
2. 涉及前后端的功能完成后，必须确认真实联调通过再勾选。
3. 只完成静态页面或 Mock 数据时，不标记真实业务完成。
4. 修改 MVP 范围前先确认是否影响目标日期。
5. 每次更新本清单时，同步修改前端和后端仓库中的同名文件。
